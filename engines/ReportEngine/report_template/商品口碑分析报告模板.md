### **商品口碑分析报告模板**

- **1.0 摘要与核心发现**
  - 1.1 商品口碑总览
  - 1.2 关键指标表现
  - 1.3 主要结论与选品启示
- **2.0 评分与评论量分析**
  - 2.1 评分分布（星级占比）
  - 2.2 评论量趋势
  - 2.3 认证购买（Verified Purchase）占比
- **3.0 情感态度与关键议题**
  - 3.1 正面/中性/负面情感分布
  - 3.2 高频关键词与联想词云
  - 3.3 核心议题（质量/价格/物流/体验）分析
- **4.0 优缺点归因分析**
  - 4.1 主要优点与好评场景
  - 4.2 主要痛点与差评归因
  - 4.3 好评/差评典型评论摘录
- **5.0 用户画像与购买动机**
  - 5.1 使用场景与人群特征
  - 5.2 核心购买决策因素
  - 5.3 复购与推荐意愿信号
- **6.0 口碑风险与机会洞察**
  - 6.1 高频差评议题追踪
  - 6.2 潜在口碑风险预警
  - 6.3 正向口碑机会挖掘
- **7.0 结论与选品建议**
  - 7.1 商品SWOT分析总结
  - 7.2 产品与详情页优化建议
  - 7.3 客服与售后改进建议
  - 7.4 下一周期监测重点
